# Кросс-валидация и подбор гиперпараметров

Занятие курса «Искусственный интеллект» для 9 класса. Ученики выясняют, почему оценка качества по одной валидационной выборке ненадежна, и пишут на чистом Python K-блочную кросс-валидацию, стратифицированную кросс-валидацию и скользящий контроль по одному объекту. С их помощью подбираются по сетке число соседей для метода k ближайших соседей и глубина дерева решений. В конце ученики встраивают подготовку данных внутрь каждого блока и своими руками получают утечку данных, которая дает 80 % точности на случайных числах.

## Теория (презентация)

1. **Одной валидации мало.** Параметры и гиперпараметры модели. Эксперимент со ста разбиениями, которые дают сто разных оценок. Лучшее число соседей зависит от случайного разбиения.
2. **Кросс-валидация.** Каждый объект один раз попадает в валидационный блок. Перемешивание и нарезка блоков, сравнение одной валидационной выборки с пятью блоками, стратификация для редкого класса, скользящий контроль по одному объекту, выбор числа блоков.
3. **Подбор гиперпараметров.** Перебор по сетке на одних и тех же блоках, кривая кросс-валидации для выбора числа соседей, глубина дерева решений на наборе Wine, протокол из четырех шагов от сетки до проверки на тестовой выборке.
4. **Утечка и честная оценка.** Подготовка данных внутри каждого блока, утечка через отбор признаков (82 % на случайных числах), вложенная кросс-валидация.
5. **Практика.** План из одиннадцати заданий.

## Практическая работа

| Задание | Что пишем | Главный результат |
|---|---|---|
| К1 | `mean_std`, `holdout_score` | одна валидационная выборка дает от 79 % до 95 % |
| К2 | `k_fold_indices`, `split_by_fold` | номера объектов нарезаны на K блоков |
| К3 | `cross_val_score` | оценка метода k ближайших соседей кросс-валидацией: 87,6 % ± 2,3 % |
| К4 | `stratified_k_fold_indices`, `count_in_folds` | редкий класс есть в каждом блоке |
| К5 | `loo_folds`, сравнение разного числа блоков | сколько блоков взять |
| К6 | `make_grid`, `grid_search` | лучшее число соседей |
| К7 | перебор глубины дерева решений на Wine | лучшая глубина и итоговая проверка на тестовой выборке |
| К8 | `cross_val_score_prep` | подготовка данных внутри каждого блока |
| К9 | `fit_selector`, `apply_selector` | утечка данных через отбор признаков |
| К10 | сто случайных разбиений | разброс оценки в 4,4 раза меньше, чем у одной валидационной выборки |
| К11 | полный протокол и сверка с `GridSearchCV` из scikit-learn | итоговая модель и честная оценка на тестовой выборке |

Задания повышенной сложности: вложенная кросс-валидация, повторная кросс-валидация с разными начальными значениями генератора случайных чисел, правило одной стандартной ошибки, случайный поиск гиперпараметров, кросс-валидация для кадров одного видео.

**Правило работы:** внутри своих функций разрешены только списки, словари, циклы, модули `math` и `random`. Библиотеки `numpy`, `pandas` и `scikit-learn` не используются. Библиотека `scikit-learn` нужна только для загрузки набора Wine и для сверки в последнем задании, `matplotlib` используется только в готовых ячейках с графиками.

## Данные

1. Синтетические данные беспилотного автомобиля: объекты на дороге (пешеход, велосипедист, автомобиль) с признаками «скорость», «длина», «высота» и «расстояние до объекта».
2. Набор Wine из scikit-learn: 178 вин трех сортов, 13 химических признаков.
3. Набор из случайных чисел (60 объектов, 1000 признаков) для задания об утечке данных.

## Как работать

1. Откройте ноутбук в Jupyter или Google Colab.
2. Прочитайте теорию в начале ноутбука: все задания опираются на нее.
3. В ячейках с заданиями замените `...` своим кодом (подсказка написана в комментарии `# <--`).
4. Сверьте напечатанное значение с тем, что указано после слова «ожидается».
